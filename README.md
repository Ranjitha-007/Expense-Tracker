# Personal Expense Tracker

This is a simple expense tracker web application built using HTML, CSS, and JavaScript. It helps users manage their income and expenses and track their financial balance.

## Features

- Add income and expense transactions
- Delete transactions
- Automatic balance calculation
- Income and expense totals
- Expense vs Income percentage
- Data stored using localStorage (persists after refresh)

## Technologies Used

- HTML
- CSS
- JavaScript
- LocalStorage
